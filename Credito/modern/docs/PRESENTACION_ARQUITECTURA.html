Sistema legado · Antes

CREDIX / CREDICONFIABLE (VENDIX)

Sistema comercial de ventas y crédito usado en oficinas: crédito, caja, bóveda, clientes, ventas, almacén e informes — todo en una aplicación web clásica servida por IIS.

Producto

  • UI: CREDIX / CREDICONFIABLE
  • Marca interna: VENDIX
  • Solución: Creditos.sln

Quién lo usaba

  • Administrador · Analista/Gestor
  • Cajero · Aprobador
  • Encargado / Gerencia · Lectura

Proyectos

  • Web (MVC + vistas Razor)
  • ITB.VENDIX.BL (negocio)
  • ITB.VENDIX.DA (EF6 + SQL)

Sistema legado · Stack

Tecnologías que usaba

Plataforma

  • .NET Framework 4.8
  • ASP.NET MVC 5.3
  • Entity Framework 6.5 (Database First / EDMX)
  • Hosting: IIS

Interfaz e informes

  • Plantilla mango + jQuery 1.7 / jQuery UI
  • Grillas jqGrid (JSON desde controllers)
  • Reportes RDLC + ReportViewer 15 (~37 reportes)
  • Sin SPA: cada pantalla se renderiza en el servidor

Sesión y seguridad

  • Login: usuario + clave + oficina
  • Sesión ASP.NET + VendixGlobal en memoria
  • Menú: usp_MenuLst → sidebar accordion
  • Filtro [Autenticado] / SessionHelper

Datos

  • SQL Server · BD CREDITO
  • Conn: VENDIXEntities
  • Motor de dinero: procedimientos usp_*
  • Reloj de negocio: usp_FechaBD

Sistema legado · Operación diaria

Cómo se trabajaba en la práctica

Pantallas

  • Crédito: ficha, estados CRE/PEN/AP1/APR/DES, aprobación, simulador
  • Caja: diario, chica, saldos, verificar pagos, tickets RDLC
  • Informes: ReporteController + ~37 .rdlc (plan pagos, kardex…)

Límites que motivan modernizar

  • UI acoplada a MVC + jQuery (sin PWA / offline de campo)
  • Dependencia de RDLC / ReportViewer
  • Validación dispersa entre BL y vistas
  • Sesión servidor; evolución incremental difícil

Lo que no se cambia: SQL Server, usp_*, menú ACL y las reglas de crédito/caja.

Stack tecnológico · Moderno

Capas de la plataforma nueva

Frontend

  • React 19 · Vite · TypeScript
  • Ant Design 6 · React Router 7
  • TanStack Query · PWA
  • Mapas: Leaflet + Google Maps

Backend y datos

  • .NET 10 Minimal APIs · JWT
  • Dapper + SQL Server (BD CREDITO)
  • QuestPDF · ClosedXML
  • HealthChecks · OpenTelemetry

Seguridad

  • Login JWT (usuario + oficina)
  • Refresh token + rate limit
  • Menú ACL por rol
  • Escrituras atadas a la oficina del token

Despliegue

  • Dev: Vite + dotnet run
  • Staging: Docker + nginx
  • Prod: Azure App Service / IIS + ARR
  • Proxy: /app → SPA · /api/v1 → API
