# Fase 5 — Stack UI

Se eligió React + TypeScript + Vite por velocidad de migración, compatibilidad con SPA incremental y facilidad de convivir con MVC mediante proxy.

La SPA usa Ant Design, React Query, rutas lazy y componentes Credix (`CredixPage`, `CredixDataTable`, `CredixInformePage`, `CredixCrudPage`).
